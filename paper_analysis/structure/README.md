# Per-residue attribution on the structure

Paints the chimera block effects onto an AlphaFold model of parent 1, at per-residue
resolution.

## Regenerate

```bash
python make_structure_figure.py
```

All outputs land in `../exports/`, which is gitignored. Then render from the ChimeraX GUI
(its macOS build has no headless OpenGL):

```
open ../exports/view_attribution.cxc
```

That colours the model and writes `attribution_chimerax.png` beside it. To re-save after
rotating: `save attribution_chimerax.png width 2000 supersample 3 transparentBackground true`

## Do not delete `block_alignments.json`

FAMSA is not deterministic on block f0, the only block where the parents differ in length.
Eight runs on the same six sequences produced three different alignments, moving the peak
attribution between 0.176 and 0.212 — about 20% on the number the figure leads with. The
overall pattern is stable (r = 0.997 across perturbed alignments); the peak is not. This
file pins the alignment the published numbers came from.

## What the map does and does not show

Each chimera inherits a whole block from one parent, so within a block every polymorphic
residue is perfectly correlated across the library. No per-residue effect is identifiable
from these data. What is well defined is a decomposition: the block effect is written as a
sum over alignment columns and solved for the minimum-norm coefficients, so residues shared
between parents get one coefficient and a residue common to a strongly positive and a
strongly negative parent is drawn toward zero. It reconstructs the block effects exactly.

The consequence is that every column where parent 1 carries a residue found in no other
parent receives an identical coefficient — 49 residues, 8 distinct values, one per block.
Residues acquire distinct values only through how they are *shared*.

So the figure shows how distinctive a residue is among the six parents, weighted by its
block's effect. It is not a measurement of what individual residues do. The legend must
say so.

## Colour scale

Linear, clipped at the 99th percentile of |attribution| (±0.0846); 5 residues saturate and
are flagged `clipped_in_figure` in the table. Within the limit, colour is proportional to
attribution. The colourbar carries extend arrows and prints the true extremes (−0.13,
+0.21) past the tips.

`CLIP` is defined once in `make_structure_figure.py` and drives the structure, the bar and
the table together.
