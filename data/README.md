# Data & weights

The PRAXIS repository commits only code and small reference files. Large artifacts are hosted
externally and restored on demand.

## Restore everything

```bash
bash data/download_data.sh      # benchmark oracle datasets
bash agent/setup.sh             # ESM2-650M + Tranception Large weights
```

## What lives where

| Artifact | Size | Source |
|----------|------|--------|
| Benchmark DMS oracle datasets (`*_SeqFxnDataset.pkl`, 4 proteins) | ~80 MB | Zenodo (DOI: `TODO`), via `download_data.sh` |
| ESM2-650M weights | ~2.5 GB | `agent/setup.sh` (Meta/HF) |
| Tranception Large weights | ~2 GB | `agent/setup.sh` (marks.hms.harvard.edu) |
| Precomputed embeddings / zero-shot predictions | regenerable | produced by `agent/precompute_*.sh`, or Zenodo |
| Closed-loop result databases (SQLite) | ~25 MB | Zenodo (DOI: `TODO`) |

`benchmark_data_manifest.txt` lists the exact files and target paths that `download_data.sh`
restores into `agent/insilico_analysis/`.

## Notes

- The 4 benchmark datasets are derived from published deep-mutational-scanning studies
  (GFP, GB1, PAB1, UBE4); see the paper for the original references.
- Intermediate model checkpoints from benchmark runs (~40 GB) are **not** published — they are
  regenerated by re-running the benchmark scripts.
